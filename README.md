## Data Storage

This application uses browser local storage to save notes.

### Storage Features
- Notes remain available after refreshing the page.
- New notes are added to the existing collection.
- Notes are stored locally in the current browser.
- Clearing browser site data may remove saved notes.

### User Experience

The application provides a simple interface
for writing and reviewing daily notes.
## Manual Testing Checklist

- [ ] Write a note and verify that it appears in the list.
